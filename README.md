# Asistente de documentos con IA

Aplicación Streamlit para subir PDFs, indexarlos en una base vectorial y hacer preguntas sobre su contenido en español.

## Requisitos

- Python 3.10+
- Una API key de Groq

## Instalación

```bash
pip install -r requirements.txt
```

## Ejecución

```bash
streamlit run app.py
```
